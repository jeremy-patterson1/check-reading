# Example checks

## Synthetic examples

These were generated by `scripts/make_examples.py` and contain only invented
names, amounts, account numbers, and routing numbers:

| File | Payee | Amount | Date | Check number |
| --- | --- | --- | --- | --- |
| `demo_check_1.pdf` | Acme Office Supply | 124.50 | 2026-09-14 | 1042 |
| `demo_check_2.pdf` | Jordan Ellis | 1,250.00 | 2026-10-02 | 2210 |
| `demo_check_3.pdf` | Northwind Traders | 89.99 | 2026-10-15 | 3187 |

Regenerate them from the repository root:

```bash
python scripts/make_examples.py
```

## Public sample

`canadian_cheque_sample.png` and `canadian_cheque_sample.pdf` are derived from:

- Source: <https://commons.wikimedia.org/wiki/File:CanadianChequeSample.png>
- Author: Airodyssey (Sergio Ortega)
- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- Changes: converted the PNG to a PDF page; the check content was not changed.

The cheque depicts a fictional bank and fictional account details. It is a
low-resolution image, so it is a useful reminder that OCR quality depends on
the scan; the tool may report missing fields for it.
